# بنية Rounder: Modular Monolith

مشروع Laravel واحد، عملية نشر واحدة، وقاعدة MySQL واحدة. المجالات وحدات كود مستقلة وليست خدمات شبكية منفصلة.

## الوحدات
Identity للحسابات والأدوار والمصادقة؛ Properties للمباني والوحدات والزيارات؛ Catalog للخدمات والباقات والاشتراكات؛ Bookings للحجوزات؛ Emergencies للطوارئ؛ Providers للمزودين والعقود والعمولات؛ Finance للمدفوعات واتحاد الملاك؛ Community للإعلانات والمجتمع والمبادرات؛ Facilities للمرافق؛ Notifications للإشعارات؛ Dashboard للتقارير؛ Settings لتفضيلات المستخدم.

## مسار الطلب
Routes → FormRequest → Controller → Service → Eloquent Model → MySQL.
- Routes تحافظ على العناوين وأسماء المسارات الحالية.
- FormRequest تطبق التفويض وقواعد المدخلات والتطبيع قبل استدعاء الخدمة.
- Controller ينقل البيانات المتحقق منها وهوية المستخدم للخدمة، ويحول الناتج إلى JSON أو View أو Redirect.
- Service تستقبل array وUser ومعرفات الموارد، ولا تتلقى HTTP Request أو تنشئ HTTP Response.
- العمليات المعدِّلة مجمعة في معاملات. العمليات التي كانت تستخدم معاملة داخلية تظل آمنة ضمن المعاملة الخارجية.
- Events تصدر عبر DB::afterCommit؛ لن تنطلق عند rollback.
- Models تحتوي حقولاً وعلاقات وcasts/scopes فقط؛ لا يوجد workflow فيها.
- Enums تعرّف الخيارات والحالات الثابتة، بينما الكتالوج القابل للتعديل يبقى في MySQL مرتبطاً بالـIDs.
- DomainViolation تصف سبب رفض العملية. تحويل السبب إلى كود HTTP يتم في bootstrap/app.php.

## حدود الاعتماد
يجوز للعلاقة أن تشير إلى Model من مجال آخر عبر import صريح، لأنها تمثل مفتاحاً أجنبياً في قاعدة البيانات المشتركة. عمليات تعديل مجال آخر تمر بخدمة أو حدث. تقارير Dashboard تجمع قراءات من عدة مجالات.
بعض استعلامات العرض تستخدم joins عبر Eloquent للحفاظ على الأعمدة الحالية. لا يوجد DB::table أو DB::raw في Services أو Controllers.

## الطبقات المشتركة
app/Core تضم قواعد FormRequest، اللغات المشتركة وأخطاء المجال.
app/Services وapp/Actions وapp/Jobs مخصصة للقدرات العامة عند الحاجة. لم نضف أعمال خلفية أو Observers بلا أثر وظيفي؛ مجلدات Observers جاهزة لإضافات ذات غرض واضح.
عند إضافة Observer لتأثير جانبي، يجب أن يعمل بعد commit وأن يُسجَّل صراحة؛ لا تنقل قواعد التسعير أو الصلاحيات إليه.

## التعديل الآمن
1. حدد المجال أولاً.
2. أضف قواعد المدخلات داخل Requests.
3. أضف حالة ثابتة إلى Enum عند الحاجة، وحدث بيانات lookup المترجمة.
4. نفذ العمل داخل Service. لا تستخدم request() أو response() فيها.
5. أبقِ Controller قصيراً.
6. أضف سيناريو Feature لاختبار الصلاحيات وقواعد العمل.
7. شغّل الاختبارات على قاعدة rounder_test في MySQL.

## الاختبارات
ModuleArchitectureTest يمنع عودة الاستعلامات إلى Controllers واعتماد Services على HTTP.
EloquentSchemaTest يتحقق من علاقات النماذج مقابل الجداول.
اختبارات العمليات تحافظ على عقود الـAPI وملكية الساكن ولقطات السعر والحصص.
