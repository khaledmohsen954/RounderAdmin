# بوابة مزود الخدمة

- تسجيل الدخول من `/provider/login` باستخدام رقم الهاتف أو البريد وكلمة المرور.
- حساب المزود حساب `users` عادي بدور `provider`. ربط مستخدمي الفريق بملف المنشأة وتخزين صلاحياتهم يتم في سجل المستخدم نفسه؛ لا يوجد جدول مستقل للفريق.
- لا يدخل المستخدم إلى لوحة المنشأة قبل اعتمادها وقبول العقد. حساب الفريق يرث اعتماد المنشأة والعقد المرتبطين به.
- تعرض اللوحة الطلبات المسندة إلى المنشأة، وأسعارها وحالات مراجعتها، وطلبات الطوارئ المسندة إليها.
- إنشاء طلب خدمة يختار ساكنًا ووحدة وخدمة مرتبطة بالمنشأة. يُنشأ الطلب بالحالة `pending` ثم يمر بالحالات `confirmed` و`in_progress` و`completed` عبر خدمة دورة الطلبات المشتركة، مع احتساب العمولة عند الإتمام.
- تُحفظ الصلاحيات المسموح بها في `users.permissions`، وتُفحص على الخادم عبر وسيط `provider`. يستطيع المستخدم الذي يملك صلاحية إدارة المستخدمين إنشاء مستخدمين بدور `provider` وربطهم بملف منشأته؛ ولا يمكنه منح صلاحية لا يملكها.
- أسعار مزود الخدمة مقيدة بملف منشأته. الأسعار الجديدة أو المعاد إرسالها بعد الرفض تبقى بانتظار مراجعة الإدارة قبل إتاحتها للعملاء.
