مسارات إدارة الويب مثل /admin/providers وجرس إشعارات الأدمن تستخدم session/CSRF؛ ليست جزءًا من Resident Bearer API ولا تنطبق عليها بيانات دخول التطبيق.

## المتغيرات
- base_url: مثال http://localhost:8000، وليس رابطًا لسيرفر منشور.
- token: يُحفظ عند الدخول/التسجيل ويُمسح بعد تسجيل الخروج.
- locale: ar أو en أو ur. بعد الدخول تتقدم لغة الحساب المخزنة على Accept-Language؛ استخدم PUT profile لتغييرها.
- home_id: المفتاح من homes، محفوظ تلقائيًا بعد link.
- resident_home_id: المفتاح من resident_homes لعضوية هذا المستخدم، **ليس home_id**. لا يعيده homes/link أو homes حاليًا؛ استخرجه من قاعدة البيانات/بيانات الإدارة.
- service_id وservice_package_id: من استجابتي الخدمات والباقات؛ اختر IDs بنفسك.
- emergency_type_id وfacility_category_id: من emergency_types وfacility_categories لفئات نشطة. لا توجد لهما lookup endpoints مستقلة حاليًا.
- property_code وunit_label: عقار وشقة مسجلان؛ لا تستخدم أمثلة غير موجودة.
- phone: رقم تجريبي تملكه بصيغة دولية مثل +966 ثم الرقم، وليس رقمًا عشوائيًا عند استخدام بيئة متصلة بخدمات فعلية.
- booking_id/subscription_id/emergency_request_id/visit_id/post_id/facility_report_id: تُحفظ من عمليات الإنشاء الناجحة.
- initiative_id وnotification_id: من نتائج القائمة المناسبة.
- scheduled_at/starts_at/ends_at: يمكن ضبط ISO8601 يدويًا؛ عند تركها فارغة تُحسب مواعيد الغد، والنهاية بعد البداية بساعة.

## قواعد مهمة
- الاشتراك المدفوع يبدأ pending؛ هذا المسار لا ينفذ دفعًا.
- إلغاء الاشتراك يخص الطلب المعلق فقط. إلغاء الطوارئ مشروط بحالتها. التقييم يحتاج حجزًا مؤهلًا.
- إنشاء الزيارات/المنشورات/بلاغات المرافق يعتمد العضوية الافتراضية وفق التنفيذ الحالي.
- IDs ليست قيمًا ثابتة بين البيئات. لا نفترض أن أول سجل هو المطلوب.
- الاستجابات ليست موحدة بالكامل: بعضها data array، وبعضها paginator داخل data؛ حافظت المجموعة على العقود الحالية.
- 401: توكن مفقود/منتهي؛ 403: صلاحية؛ 404: سجل غير موجود أو غير متاح؛ 409: تعارض؛ 422: تحقق؛ 429: تجاوز المعدل.
- سكربت الاختبار يتوقع نجاح الطلب؛ لا يعتبر رد الخطأ نجاحًا. هذه اختبارات Postman جاهزة للتشغيل وليست تقرير نجاح على سيرفرك.

## التحقق أثناء الإعداد
تمت مطابقة كل method/path مع ملفات Routes/api.php وقواعد FormRequest والخدمات، وفحص JSON وسكربتات JavaScript. لم يتم إرسال أي طلبات فعلية إلى سيرفر إنتاج، ولم تتغير عقود الـAPI.
